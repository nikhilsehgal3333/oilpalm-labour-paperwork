Methodology

Results and note · Note as PDF · Code on GitHub · Coding log

An independent desk study by Nikhil Sehgal on public documents only. It is not an output of the University of Bonn, the PALMWORK project or any company named.

This page shows how the study went from six public documents to its findings. Every count on this page is read from the result files in the repository when the site is built.

The question

How do the policy documents of India's oil palm mission (NMEO-OP) and the sustainability disclosures of the processors expanding into North-East India represent labour (on plantations, in mills and in social reproduction) and its link to the environment? What do they leave out that only fieldwork with workers can show?

The approach in six steps

  1. Collect the documents
    Six public documents: the 2021 approval of the oil palm mission, a December 2025 Lok Sabha answer on the North-East, the FY2024-25 BRSRs of Godrej Agrovet and Patanjali Foods, the RSPO and Sattva smallholder study, and the 2024 oilseeds-mission guidelines as context. Each file is fingerprinted (SHA-256) so that a rerun can prove it used the same documents; the text is extracted page by page.
    Output: data/corpus.csv, data/corpus_lock.csv. The documents themselves stay with their owners and are not published.
  2. Fix the codebook before coding
    Ten codes taken from the four literatures named in the PALMWORK project (labour regime analysis, feminist labour geography, environmental labour studies, political ecology), and three levels for each document and code: explicit for oil palm, generic (company-wide or scheme-wide), absent.
    Output: codebook.yaml. One change after the first round (growers and hired workers split), logged below.
  3. Find candidate passages
    A keyword search per code finds 567 candidate passages and marks those that sit near an oil palm or North-East word. Keywords only find candidates. They decide nothing.
    Output: results/candidate_counts.csv.
  4. Code the passages, in three layers
    For each document and code, the strongest candidates go to a coding sheet. A keyword rule proposes a level; a first review reads each passage and corrects the proposal (41 proposals changed, 32 passages judged not relevant, 1 passage added by hand); the author then checks it. A passage can also count for a second code.
    Output: results/coding_log.csv (all three layers for every row, without the document text) and results/coded_passages.csv (short excerpts with page numbers).
  5. Check what decides each result
    The level of a cell is the strongest relevant passage. The author checked 36 rows in two rounds (20 at the first checkpoint, 16 at the second), covering the deciding passage of all 36 non-empty cells. The author changed 0 of the first-review levels.
    Output: results/presence_matrix.csv.
  6. Report from the files, not by hand
    A script writes the figure, the numbers file and the results block of the README and the note. Tests check that every number in that block comes from the numbers file, that the text is clean, and that the pipeline gives the same output when it runs again.
    Output: results/manifest.json, results/presence_matrix.png, NOTE.md, NOTE.pdf.

Levels. explicit: the document says something about the code for oil palm work, workers, growers or places. generic: it addresses the code company-wide or scheme-wide, without tying it to oil palm. absent: it does not address the code. On the coding sheet a passage can also be not relevant when a keyword matched in another sense (for example "Union Cabinet" for the code on trade unions).

Limits

  • Documents show what organisations choose to say. Absence in a document is not absence on the ground.
  • BRSR covers a company's own workforce, so it cannot be expected to show workers employed by growers or contractors.
  • The NMEO-OP operational guidelines are missing.
  • One coder: the author checked every deciding passage, but no second coder assessed reliability.
  • Six documents, in English, from one financial year for the companies; keyword search can miss passages that use other words.
